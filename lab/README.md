### 项目深读与题库

- 48 个专题组织为 8 个学习块，共 480 分钟净学习时间，休息另计。33 个专题以项目实现为主、15 个为扩展教学；不能把一天速览等同全部熟练。
- 每课包含源码证据、当前实现、设计取舍、两种替代方案、实验预测、预期结果、故障注入、闭卷问答和验收点。设计理由是对代码的工程分析，不虚构当时的选型经历。

- 原 C 验证通过独立 Python 进程运行，避免 DLL 的静态全局控制器覆盖主实验台。此过程是宿主控制逻辑执行，不是硬件实测。
- 预测、复盘笔记、三项自评和闭卷记录保存于浏览器，可导出 JSON。自评不等于自动能力认证。
- 公司题库覆盖 44 家企业，共 237 道整理题与项目迁移练习，其中汇川 65 道、12 条公开来源。面经主题题 132 道、迁移练习 105 道，全部追问与答案为教学整理。按公司、关键词、证据类型和今日关联范围筛选。
- 每条来源标记发布/编辑日期及正文或摘要可见范围；候选人回忆不等于官方题库。不同部门、硬件/电机/嵌入式岗位有差异，不宣称穷尽历史面试。

## 启动

在项目根目录运行：

```powershell
python lab/server.py --open
```

也可以双击 `lab/start_lab.cmd`；实验台已经运行时会直接打开现有页面。浏览器地址为 `http://127.0.0.1:8765`。端口被占用时可给 `server.py` 加 `--port 8766`。

需要 Python 3.10+ 和宿主 C 编译器（Windows 支持已安装的 Visual Studio C++ 工具，或 GCC / Clang）。首次启动自动编译；修改 C 源码后重启服务会按源码哈希重新构建。无需 Python 第三方包，不连接真实设备，不读取 secrets.h。

## 使用顺序

1. 选择第一课“温度与滞回”，自动定位对应源码。
2. 先预测场景结果，再点击“运行第 1 步”。
3. 界面回放本轮实际执行的关键 C 语句，显示变量快照。
4. “下一代码步”可手动推进回放。控制函数返回后才提交引脚动画。
5. 温度依次为 25、29、27、25°C，风扇应依次关闭、开启、保持开启、关闭。
6. 展开面试题说明，并用输入控件自行改变条件验证。

点击开发板或传感器可直接跳转到其对应程序。所有控制变量、6 项可配置阈值、手动输出、发芽率输入、告警、指令结果和 74 字节帧都可查看。

“150 个专题 · 学习与接线”是主学习目录，访问 `http://127.0.0.1:8765/?topic=1` 可直接进入。每个专题有基本原理、预测练习、代码、追问与参考资料，支持搜索和本地复习标记。学习顺序为 C 语言 → 控制逻辑 → STM32 基础 / GPIO → 定时器 / ADC → 通信 → DMA / 中断 → FreeRTOS → ESP32 / MQTT → 调试 / 升级 → 岗位拓展。结合江协官方课程的基础知识路线，并明确区分其 F103 / 标准库示例与本项目 F407 / HAL。

“160 题学习路线”保留原题编号、分类与面经来源，全部题号都已关联到专题。150 个专题复用 45 个可执行的原理模型，并连接 15 个接线场景和 12 个原 C 控制实验；不是 150 套完整硬件仿真。高级题中的完整系统推导和模型未实现部分，会在该专题中明确说明。

## 开发板原理实验

点击“打开开发板原理实验”，可以学习 10 块：芯片结构与 RCC 时钟、GPIO、TIM4 PWM、I²C/BH1750、DHT11 脉宽、USART、循环 DMA、任务队列、NVIC/临界区、IWDG 独立看门狗。

每块都有基本原理、芯片功能模块图、模型参数、波形或缓冲区、对应源代码和常见追问。当前步骤会高亮对应语句和所在函数，并自动滚动；可暂停、前后单步或拖动进度。点击芯片内部模块可跳到它参与的第一步。题库中的“相关原理”可直接进入对应模型，但不表示该面试题所有进阶内容已覆盖。

PWM 可以改变 PSC、ARR 和占空比；GPIO 可以切换输入、推挽、开漏和上拉；I²C 可以注入 NACK；DHT11 可以改变单个位的高脉宽；UART 可以改变待发字节；DMA 可以观察跨界和恰好写满一圈。默认值及代码位置对应当前工程，变化的模型参数不会修改原固件，也不改变主实验台状态。

这 10 块是明确标记的外设原理模型，不运行 HAL 或 MCU 指令。CPU、总线、外设之间的线表示功能关系，不是精确芯片版图。DHT11 使用合成脉冲；DMA 的接收历史计数仅存在于模型，当前固件没有整圈覆盖诊断。源程序中发现的边界行为按原样展示，未擅自修改固件。

## 实验

12 课包括：滞回控制、水泵最长运行与冷却、光照更新与 PWM、液位稳定和超时保护、手动模式和重复命令、传感器失效、发芽率条件、CRC 错帧、32 位时间回绕、任务周期关系、结构体、断网本地自治。

控制核心每 100 ms 执行，环境每 2 s 采样。输入变化通常要等下一次采样才进入控制；低液位输入每个控制周期检查。连续运行可以选择 1× / 5× / 20×，也可推进 100 ms 或 2 s。

快进时保留发生输入采样值、需求、保护或输出变化的控制周期，并保留最后一个周期；重复且状态不变的中间周期省略。回放时钟显示该观察点实际对应的模拟时刻。

“连续运行”默认开启“代码跟随（慢放）”：每次推进 2 秒模拟时间，再依次展示保留下来的关键周期，源码高亮与引脚动画同步。1×/5×/20× 调整演示节奏，慢放不代表真实时间速度。关闭代码跟随后可快速观察整体状态；选择源码文件或点击器件会暂停连续运行。

## 实现与边界

### 虚拟接线实验台

访问 `http://127.0.0.1:8765/?bench=fan` 可直接进入风扇与种菜机联动课；`?bench=gpio` 进入 GPIO 接线课。也可以从专题中的“进入对应接线实验”打开。接线板与种菜机同屏，画布支持缩小到 65%。

1. 先读本课目标与接线步骤。点一个金色端子，再点另一个端子完成接线；点导线或下方导线列表可以拆除。找不到端子时，点“高亮下一根线的起点”，查看两端名称后点“连接这两个端子”；也可以用两个下拉框自行选择端子。
2. “载入接线示例”用于快速看效果，“清空本课导线”用于自己练习。各课导线保存在本浏览器，不会改变真实固件。
3. 示波器必须接地夹和探头。CH1 为黄色、CH2 为青色；按信号时间尺度调时基与 V/div，波形超量程时会提示。
4. 点“运行并跟随代码”或“下一步”，同时看 LED / 灯条、引脚、波形与代码。点引脚可查看排针号、芯片封装脚号、项目配置和手册链接。
5. 点芯片或“放大芯片 100 脚”查看全部 LQFP100 封装脚。P1/P2 的 100 个排针位置是另一套编号，不能直接互换。
6. 做风扇实验时，完成 8 根示例连线，把右侧温度设为 29°C，点“接好后，运行种菜机 2 秒”。代码按原 C 的实际观察点回放，风扇随输出启动。拆掉 PD12 到驱动器 G 的线，风扇停转；接回后恢复。将温度降至 25°C 再运行，原 C 滞回控制关闭风扇。此例使用自动控制模式；若之前开启了限时手动模式，应先在主实验台结束手动控制。
7. 旁边种菜机显示补光、风扇、滴灌、喷雾、补液和液位。其余模块按已安装处理，本课负载仍受实际接线通路限制。单个专题的原理模型与原 C 输出分开标注，不会把内部算法步骤强行变成执行器动作。

共有 15 个接线教学场景：GPIO 输出、液位输入、PWM、DHT11、BH1750 I²C、UART、DMA、任务队列、ESP32/MQTT、故障定位、风扇驱动、水泵驱动、ADC 电位器、SPI Flash 和 EXTI 按键。基础外设与江协官方课程入口关联；每课有基本原理、项目设计原因、测量步骤和关联题号。未杜撰视频分集编号，也未把项目拓展称为原视频章节。

接线台采用理想信号模型。GPIO 闪灯使用单独展示的教学 C 例程解释；其余主要定位项目原代码。JavaScript 展示 HAL 调用背后的原理，不执行 MCU 指令或实际 HAL。MOS 驱动、电源和传感器模块为教学模型，不是可直接照抄的已验证电路设计。GPIO / PWM、串口与存储动画的时间被减速；波形按标注单位计算。

ADC、SPI、EXTI 是明确标注的扩展教学例程，不属于原项目已经使用的外设。RTC、CAN、内存管理、调度、PID、Linux 等在专题区提供计算或状态模型与代码分析，没有全部扩展成可接线电路。CAN 模型只演示标准 ID 仲裁，堆模型只演示容量分配，电机模型不运行完整 FOC，PLL 模型不运行完整 SOGI；相应高级内容通过公式、代码和手工推演讲解。

- `build.py` 从现有 `common/planter.c` 生成临时观察版本，在选定语句后插入只读 `lab_trace()`，原文件保持不变。
- `bridge.c` 调用真实 `planter_init/sample/command/step/telemetry` 与 `proto_encode/feed`，导出状态快照。
- `engine.py` 提供可控模拟时间、传感器输入和教学场景。
- `server.py` 仅监听本机回环地址，提供状态和操作接口。
- `web/` 是无外部依赖的动画与源码浏览界面。

回放展示已经完成的 C 调用中的关键观察点，不是暂停 CPU 的机器指令调试器。GPIO/PWM 提交阶段按原 `app.c` 调用位置作模型展示。中断、DMA、I²C、FreeRTOS 内核、Wi-Fi/MQTT、摄像头/YOLO 不在本实验中真实运行。芯片外形与连线为功能示意，非精确板图。

宿主 sizeof/offsetof 不能代替 ARM ABI 的测量。显示电压、主频为配置值。液位显示高低而非百分比。环境联动是明确标记的简化教学模型，默认关闭，不可用于农业或硬件性能预测。

课程显示前一轮整理的题号，并区分面经题、延伸题和项目追问。模型演示和纸面分析不代表完成了芯片级验证。
