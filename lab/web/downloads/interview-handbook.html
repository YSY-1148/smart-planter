15. 开漏和推挽怎样选？I²C为什么要上拉？

  • 推挽能主动拉高和拉低；开漏高态是释放线路。

2. 结构体和联合体在存储布局上有什么区别？

  • 结构体为成员保留各自存储并可能含填充；联合体成员共享存储，其大小需满足最大成员与对齐要求。

2. CPU 在函数调用、中断和任务切换时保存的是同一套现场吗？

  • 不是。普通函数按 ABI 保存需要保留的寄存器；Cortex-M 异常硬件建立基本栈帧，可能还涉及浮点与对齐扩展；RTOS 再保存任务切换所需其余上下文。
  • 常见基本异常帧包含 R0–R3、R12、LR、PC、xPSR。定位时应确认 MSP/PSP 和 EXC_RETURN，不能拿一个固定偏移套所有情况。

3. 数组越界一定导致 HardFault 吗？不触发时该怎么发现？

  • 不一定。若写到了仍可访问的 RAM，可能悄悄破坏其他对象，直到很久以后才表现出异常。
  • 用边界检查、编译告警、适合的静态分析、保护区和可控测试尽早发现；调试时可对被意外改变的地址设置写观察点。

4. DMA 完成和串口空闲事件相近时，接收设计应如何避免重复或漏处理？

  • 不能靠一次日志观察假定永久的 ISR 先后顺序；应基于统一的生产位置或已处理区间，使两个通知走同一套幂等消费逻辑，并考虑溢出。
  • 当前工程没有启用 DMA HT/TC 与 UART IDLE 的联合接收，而是任务轮询 NDTR。若改造为事件驱动，应把同时挂起、长中断屏蔽和缓冲回绕列入测试。
