 学习路线与仿真边界

从一个判断，走到整个嵌入式系统

当前提供 150 个学习专题、45 个共享原理模型、15 个接线场景和 12 个原 C 实验。控制核心、命令校验、CRC 与帧解析执行原项目 C 代码；关键语句加入只读观察回调，源码文件保持原样。

接线与种菜机联动

连接开发板、电源、传感器、驱动器和示波器，观察引脚信号与代码。运行原 C 控制器后，种菜机按控制输出和本课接线通路呈现风扇、补光、水泵等效果。

原理模型与代码推导

外设、调度、通信和控制算法采用局部计算或状态模型。高级专题另外提供代码与推导，未运行完整 CAN 协议栈、FreeRTOS 内核、Linux 驱动或 FOC 系统，也不执行 Cortex-M 指令。

代码回放记录已完成的 C 调用中的关键语句，不是暂停 CPU 的调试器。引脚动画在控制函数返回后提交；源代码可以跟随跳转到 app.c 的输出调用。

物理环境联动、摄像头、云端和芯片外形是教学模型。液位开关不提供百分比；显示的电压、主频是工程配置值。150 个专题不等于 150 套完整芯片仿真。

每课按“理解原理 → 预测 → 接线或运行模型 → 单步看代码和信号 → 分析种菜机反应 → 联系面试题”进行。学习目录结合江协基础课程路线，明确区分 F103 / 标准库与本项目 F407 / HAL。
